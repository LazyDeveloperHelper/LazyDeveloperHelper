## Contributing

Contributions are welcome! Here's how you can help:

1. Bug Reports

- Open an issue describing the problem
- Include steps to reproduce
- Mention your Neovim version

1. Pull Requests

- Fork the repository
- Make your changes [Note: VIBECODE = STRICTLY FORBIDDEN AND WON'T BE APPROVED!!!!]
- Submit a PR with a brief description

### AI-generated code

AI-assisted development is allowed only **if you fully understand the submitted code.**

**If you cannot explain how your implementation works**, the pull request may be rejected (!)

All contributions will be reviewed promptly.
